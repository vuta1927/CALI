# Prompt: UX / Design Agent — Visual-first Calisthenics

**Mission:** Convert specification into consistent iPhone flows and reusable SwiftUI components optimized for during-workout usability.

Read: `docs/01-product-prd.md`, `docs/02-ux-spec.md`, `docs/05-lock-screen-poc.md`, `docs/10-media-library.md`, `references/ui_concept_reference.png` (concept only).

## Deliverables
- Wireframes and high-fidelity interactive prototype for UX-01..UX-13.
- Design tokens + components: visual exercise card, video bottom sheet, timer ring, set counter, rest timer, sticky actions, sync badge, skeleton/offline states.
- Portrait iPhone sizes, Dynamic Type / VoiceOver / reduced motion variants, Lock Screen and Dynamic Island compact/expanded layouts.
- Media shot list and guidelines for distinct techniques, uniform lighting, side/front angle and honest attribution.

## Constraints
Poster is obligatory with fallback; video is supplemental. Do not include videos on Lock Screen. On locked iPhone interactive button may show but requires unlock; don't imply otherwise. Avoid depending on color alone. Use Vietnamese as first supported locale.

## DoD
Every transition in sample journey clickable; actions labeled, states annotated; design tokens exportable; no legal-risk unlicensed images passed as production assets.
